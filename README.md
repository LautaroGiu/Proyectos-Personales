TaskFlow

A task and project management application built with React, TypeScript and PostgreSQL.
TaskFlow is a web application designed to help users organize their daily activities, manage projects and keep track of their tasks in one place.
The goal of this project is to build a practical and intuitive task management tool while applying modern web development concepts.

Features

Task Management: Create, edit and delete tasks.

Project Management: Create and organize projects.

Task Organization: Associate tasks with specific projects.

Data Persistence: Store application data in a PostgreSQL database.

API Integration: Connect the frontend to a custom backend through a REST API.

Technologies
React
TypeScript
Vite
Node.js
PostgreSQL
CSS

Installation

To run TaskFlow locally:

Clone this repository.

Install the frontend and backend dependencies.

Configure the environment variables using the provided example files.

Set up your PostgreSQL database.

Start the backend server and frontend development server.
